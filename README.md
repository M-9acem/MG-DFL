# Leveraging Memory for Efficient Gossip-Based Decentralized Federated Learning

This is the official repository for our paper *Leveraging Memory for Efficient Gossip-Based Decentralized Federated Learning*, presented at FLTA 2026.

We study how combining earlier model versions with multiple gossip exchanges can accelerate decentralized federated learning under a constrained network topology.
